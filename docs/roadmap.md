# Roadmap

## Completado

- Lifecycle de ventanas: create, focus, move, resize, maximize, minimize,
  restore y close.
- Z-order por desktop.
- Bounds y snapping por monitor.
- Persistencia versionada con hidratacion saneada.
- Multi-desktop.
- Multi-monitor por desktop.
- Modales owner-scoped.
- Adaptador React con provider y hooks.
- Playground funcional con drag, resize por bordes/esquinas, desktops,
  monitores, modales, taskbar y persistencia.
- Changesets y workflows de CI/release.

## Ahora

- Validar el release workflow con secretos reales de CI y acceso npm.
- Elegir y documentar la licencia antes del primer publish publico.

## Despues

- Selectors adicionales si aparecen casos de uso reales.
- Optimizaciones del adaptador React si hay presion de render medida.
- Mejoras de performance para muchos cientos o miles de ventanas.
- Politicas avanzadas de foco.

## Futuro

- Undo / redo.
- Animaciones.
- Docking.
- Plugin system.
